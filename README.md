Meine Idee war es, ein Backup-System zu entwickeln, das nicht direkt an das Minecraft-Netzwerk gebunden ist. Der BackupAgent wird separat auf dem Server ausgeführt, zum Beispiel über eine start.sh. In der Config können anschließend alle Pfade eingetragen werden, die gesichert werden sollen.. inklusive des gewünschten Backup-Intervalls.

Weitere Updates und Verbesserungen werden folgen. Ideen und Vorschläge sind gerne willkommen.
Eine englische Version wird ebenfalls noch erscheinen.
